# anolis-provider-sdk-python

A Python SDK for writing Anolis device providers.

- [Writing a provider](writing-a-provider.md): declare device types, implement
  `devices`, `read` and `call`, and run the result under the conformance
  harness.

The protocol contracts the SDK implements are defined in
[anolis-protocol](https://github.com/anolishq/anolis-protocol).
